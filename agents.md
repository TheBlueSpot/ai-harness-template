# Agents Rules

These rules are hard requirements for this repository.

- All conversations init with /caveman ultra skill
- Use `update-harness` for harness-specific architecture, UI, TypeScript, file naming, build, and test preferences.
- If `bun.ps1` is blocked by PowerShell execution policy, use `bun.cmd`.
- Do not place code examples in this file.
- Always clarify any ambiguous tasks. Never make assumptions.
- After finishing a task locate the nearest readme.md and update it as needed. if one does not exist create it. skill work under `.agents/skills/**` does not need readme updates
- MD files should contain as little references to code and more high level concepts and links to other MD files.
