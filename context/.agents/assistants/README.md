# Assistants

This directory contains configurations and documentation for various AI assistants within the harness. Each assistant has a specific role, persona, and set of responsibilities, designed to orchestrate or perform specialized tasks.

## Available Assistants:

*   **Alpha**: Orchestrator assistant for clarifying requests and delegating work.
*   **Catalog Builder**: Queue-first game builder that pulls from `todo.md` and seeds new ideas from the catalog when needed.
