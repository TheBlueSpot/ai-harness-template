# Catalog Builder Learnings

## 2026-04-29: Catalog Sweeps Should Flag README Drift, Not Only Broken Boots

Durable learnings:

* Queue throughput slows when per-game READMEs turn into source-file inventories or patrol logs because the next catalog pass has to reconstruct the actual game concept before acting.
* A cheap sweep-level README hygiene check is enough to surface local doc cleanup candidates early, so queue reconciliation and browser-playability work stay focused on the real next action.

## 2026-04-28: Shared Signals From Kojima

Durable learnings:

* Scale tutorial weight to mechanic complexity. If safe play can teach loop, use visible first interaction instead of front-loaded instruction.
* Do not rely on one-shot teaching for critical play knowledge; keep essential controls and objectives visible or easy to reopen.
* Put must-react prompts and short-lived feedback near focal action. Use edge HUD for stable opt-in state, not brief critical cues.
* Show dodge telegraphs as future collision paths with readable arrival timing, not just abstract danger flashes.
* Keep difficulty control player-legible and low-friction; prefer in-run presets or assists over opaque adaptation.
* Prioritize pre-frame input confidence and low latency before extra juice; player should often know result at button-down.

## 2026-04-28: Strongest Reusable Kojima Signals

Durable learnings:

* Teach at point of use. If first 20-30 seconds of safe play already teach loop, cut tutorial weight.
* Keep critical knowledge visible or easy to reopen. Do not make players recall one-shot instructions after failure.
* Put must-react cues on focal action, not only edge HUD. If edge placement unavoidable, duplicate with earlier telegraph or second channel.
* Telegraph dodge threats as future collision paths with clear arrival timing.
* Expose difficulty as clear in-run presets or assists. Hidden adaptation is not default win.
* Check control-response path before balance or FX tuning. Sluggish input can masquerade as unfair difficulty.

## 2026-04-29: Queue Asset Sweeps Need One Local Plan, Not Repeated One-Off Download Commands

Durable learnings:

* When several queued entries need external packs, a local batch plan cuts path mistakes and repeated auth setup faster than rerunning one-off commands.
* Keep asset sweep plans game-scoped and local so throughput rises without creating shared cross-entry buckets or muddy ownership.
