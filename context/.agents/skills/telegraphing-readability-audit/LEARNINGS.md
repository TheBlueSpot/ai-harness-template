# Durable Learnings

- Telegraph audits should lead with the response window, because players lose trust when a cue is technically visible but still arrives too late to react.
- Telegraph audits should name future-path readability explicitly, because dodge lines, charge paths, and collision previews are different from generic HUD clarity.
- Telegraph audits should separate cue legibility from general on-screen clutter, because a readable prompt can still fail if the danger path or required response is not obvious.
- Telegraphs should expose the future path early, because a cue without the collision line still leaves the player guessing.
