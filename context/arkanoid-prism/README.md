# Arkanoid Prism-Strike

Catalog entry for a browser-playable brick-breaker inside `./arkanoid-prism/`.

## Premise

Route the ball through layered prism walls, bend rebounds off the paddle, and turn one clean angle into a multi-ball clear.

## Controls

- Mouse or `A/D`: move the paddle
- `Enter`: start the run
- `Space`: fire lasers while the laser power-up is active
- `R`: restart the current run

## Power Loop

Prism bricks split the active ball into extra angles, multi-ball capsules duplicate the field, and laser capsules convert the paddle into a temporary brick-cutting tool. The run is about keeping enough control that the extra chaos still clears the layout instead of draining lives.

## Catalog Fit

This entry is self-contained and launches directly from its own folder. It follows the catalog pattern of direct browser play, clear local controls, and a high-level README that stays inside the game folder.
