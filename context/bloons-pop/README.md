# Bloons Pop-Physics

Bloons Pop-Physics is a standalone browser tower-defense entry built around readable path control instead of a giant tech tree. The run focuses on lane coverage, manual wave timing, and explosive chain pops from volatile bloons.

## Concept

- Three compact tower roles: direct dart intercepts, splash bombs, and slowing glue support
- Placement feedback that shows valid grass, blocked track edges, and current tower range
- Wave control that lets the player launch early for tempo instead of waiting through every intermission
- Chain-reaction pressure from volatile bloons that can either help the defense or punish poor spacing

## Controls

- Mouse move previews placement and range
- Mouse click places the selected tower
- `1` `2` `3` select dart, bomb, or glue towers
- `N` launches the next wave
- `F` cycles simulation speed
- `Enter` starts or restarts a run
