# Boulder Dash Cavern Run

Browser cave-routing game built around digging safe lines, collecting gems, and using falling rocks to turn the cave against its own patrols.

## Loop

- Collect every gem and open the exit before patrol routes box you in.
- Decide when to tunnel, when to push a rock, and when to let gravity clear a threat.
- Restart is immediate so each fail stays inside the routing lesson.

## Controls

- Move: arrow keys or `WASD`
- Start / confirm: `Enter` or `Space`
- Restart: `R`

## Play

Open `./index.html` in a browser to play locally.
