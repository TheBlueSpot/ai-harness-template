# Braid Time Echo

Standalone browser platformer about rewinding your own path and releasing replay echoes to solve switch-and-door routes.

## Play

Open [index.html](./index.html) in a browser to play.

## Controls

- Move: `Arrow Keys` or `WASD`
- Jump: `Up`, `W`, or `Space`
- Rewind: hold `R`
- Start or retry: `Enter`

## Loop

Recover all three memory shards, then use a rewind echo to hold the last switch while you run through the exit door.
