# Breakout: Gravity Well

Single-file browser game experiment for `context`.

- Core idea: replace paddle with mouse-driven gravity point, so positioning and timing bend ball path instead of batting it directly.
- Session flow: stylized menu, one active play state, and clear win or loss reset screens.
- Pressure sources: moving gates, patrol drones, and falling pulse shots force curved routing instead of straight-line clears.
- Resilience goal: built-in transparent sprites keep visuals self-contained, and synth fallback audio keeps play intact even when remote sound hooks fail.

Open [index.html](./index.html) in a browser to play.
