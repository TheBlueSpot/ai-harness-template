# Bubble Cluster

`bubble-cluster` is a standalone browser-playable bubble shooter entry for the catalog.

## Concept

The board hangs from the ceiling while the player banks shots off the side walls to connect color groups. Matching clusters pop, unsupported bubbles fall, and the ceiling drops lower whenever too many shots fail to convert.

## Play Loop

- Aim with the mouse or arrow keys.
- Fire with click or `Space`.
- Clear the full board before the descending stack reaches the shooter line.

## Notes

This entry is self-contained inside `./bubble-cluster/` and boots directly from `./bubble-cluster/index.html`.
