# Crush the Castle Siege-Toss

Crush the Castle Siege-Toss is a standalone browser siege game built around dialing in trebuchet shots and turning small wall failures into full structural collapses. Each fort asks for a different launch arc, but the score climbs fastest when the player breaks support columns instead of only chipping surface bricks.

## Concept

- Trebuchet tuning focused on readable angle and power adjustments instead of charge-timing chaos
- Destructible castle stacks with support loss, falling debris, and impact damage between blocks
- Structural scoring that rewards chained collapses, heavy impact breaks, and royal target takedowns
- Short three-fort run with menu, live HUD, and restartable win or loss flow

## Controls

- `Up` `Down` adjust launch angle
- `Left` `Right` adjust launch power
- `Space` fires a stone
- `R` restarts the run
- `Enter` starts or restarts from the overlay
