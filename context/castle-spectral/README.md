# Castlevania Spectral Mirror

Browser-playable catalog entry for the `context` game collection.

- Core hook: a 16-bit action-platformer slice with a spectral mirror exit, roaming skeletons, and torchlit castle traversal.
- Session flow: start from the title card, gather three sigils through one connected keep, then escape through the awakened mirror.
- Gameplay texture: whip attacks use a segmented chain swing, skeletons pressure the player with layered chase and spacing behavior, and the castle lighting stays moody through torch-based shadow masking.

Open [index.html](./index.html) in a browser to play.
