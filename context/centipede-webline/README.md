# Centipede Webline

Browser-playable arcade shooter built around lane-shift dodges, segmented insect pressure, and fast retry.

## Play

Open [index.html](./index.html) in a browser to play.

## Loop

Move through the web lanes, shoot segments, and survive the crawl as the insect breaks apart and speeds up.

## Notes

The HUD stays minimal and the restart loop is immediate so the fight stays inside the learning loop.
