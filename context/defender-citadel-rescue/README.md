# Defender Citadel Rescue

Browser rescue shooter about defending stranded civilians, intercepting abductors, and ferrying survivors back to the citadel.

## Premise

You patrol a rolling ridgeline while alien abductors dive for civilians scattered across the terrain. Break kidnappers before they climb out, catch survivors if they drop, and ferry each rescue back to the beacon-lit citadel on the left edge.

## Controls

- `WASD` or arrow keys: fly
- `Space` or `J`: fire
- `X` or `Shift`: smart bomb
- `Enter`: start
- `R`: instant retry

## Play

Open `./index.html` in a browser to play locally.
