# Dr Mario Capsule Cascade

Browser falling-capsule puzzle game about dropping two-color capsules, chaining clears, and emptying the bottle before the stack reaches the top.

## Loop

- Clear three escalating bottles in sequence.
- Chase score through hard drops and match chains.
- Recover from partial clears as loose capsule halves tumble into new alignments.

## Controls

- `Left` / `Right`: move capsule
- `Down`: soft drop
- `Z` / `X` / `Up`: rotate
- `Space`: hard drop
- `Enter`: start or restart

## Play

Open `./index.html` in a browser to play locally.
