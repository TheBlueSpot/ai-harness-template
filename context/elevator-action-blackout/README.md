# Elevator Action Blackout

Stealth-action tower run about riding elevators, reading guard sightlines, and escaping with the files before the building locks down.

## What It Is

You infiltrate a dark office tower, steal red intelligence files from upper floors, route elevators under pressure, and escape back through the lobby before guards lock the building down.

## Play Loop

- Move floor to floor with the two lift shafts.
- Read guard sight cones before crossing open hallways.
- Shoot only when you need a fast stun window.
- Unlock the lobby exit by collecting every file, then sprint back down for extraction.

## Controls

- `Arrow Keys` or `WASD`: move and ride elevators
- `Space`: fire
- `Enter`: start or retry
- `R`: instant restart

## Play

Open `./index.html` in a browser to play locally.
