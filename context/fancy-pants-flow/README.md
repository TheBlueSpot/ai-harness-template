# Fancy Pants Momentum Flow

Standalone browser sprint built around slope momentum, player alignment to the ground plane, and a fast finish-line route through a sketchbook course.

## Loop

- Push speed through rolling hills and steep notebook ramps.
- Jump off the terrain normal to keep momentum through valleys and crests.
- Scoop up squiggles for extra flow score while racing toward the finish gate.

## Controls

- `A/D` or arrow keys: run
- `Space`, `W`, or `ArrowUp`: jump
- `Enter`: start
- `R`: restart

## Files

- `index.html`: direct browser entry
- `src/Game.js`: simulation and game-state flow
- `src/render.js`: notebook world, player, and effects rendering
- `src/terrain.js`: terrain profile and collectible layout
- `src/main.js`: DOM wiring and input loop
