# Flight Control Vector Stack

Flight Control Vector Stack is a browser-playable air traffic routing game about drawing safe approach paths under increasing tower pressure. Each aircraft must be guided onto the runway that matches its color while avoiding close calls and mid-air crashes.

## Controls

- Click or tap a plane to select it
- Drag a route through open air
- End the route on the runway with the same color tag
- Tap after a loss to restart the tower shift

## Play Loop

- Route inbound aircraft before the airspace crowds
- Match each plane to its runway color
- Pull paths apart when warning rings show tight spacing
- Survive as spawn tempo rises and mistakes cost strikes
