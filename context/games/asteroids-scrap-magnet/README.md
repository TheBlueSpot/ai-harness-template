# Asteroids: Scrap Magnet

Browser survival arcade about harvesting drifting scrap under pressure.

- Core loop: break asteroids apart, pull loose scrap with the tractor beam, recover black-box caches, and turn that recovery into stronger survivability during the same run.
- Player teaching: the first run starts with in-context controls and vent logic.
- Pressure profile: edge-spawned asteroids and breach-core pulses keep positioning meaningful.
- Feedback style: the HUD stays compact and edge-anchored while beam radius, impacts, and scrap pickups stay near the focal action.
- Run arc: eighteen salvage contracts now stretch the haul into a much longer campaign with late-yard lattice, undertow, flare, and cataclysm hazards plus deeper black-box story recoveries.

Open [index.html](./index.html) in a browser to play.

## Sweep learnings

- Start flow is simple enough for first contact.
- The help card now stays off the active lane and returns on non-play states.
- Fallback art and synth keep the game playable even when local packs are absent.
- Release windows still matter; do not turn the tractor beam into a hold-only loop.
- The haul now runs through eighteen named contracts with new late-yard hazard mixes and black-box recoveries, so each stretch feels more like a chapter than a single extended wave.
- Late salvage modules now keep paying out after the original midpoint, so the back half adds new movement, vent, and intel perks instead of flattening into pure attrition.
- Each contract can surface one optional black-box cache that adds salvage, hull, overdrive, and dispatch testimony while pulling the player into off-lane recovery choices.
- The vent cue now includes a dashed release-radius ring around the ship and breach anchors drift less wildly, so the release window reads cleaner under pressure.
- Breach phases now pin a three-step vent checklist beside the active core, so charge, range, and release read near the action instead of only in the HUD chrome.
- Breach cores now absorb vent hits without ricocheting across the lane, so the target stays readable while the player lines up follow-up releases.
- Vent teaching now states the mechanic purpose in plain language: release vents pull scrap during free play and crack breach cores once the orb enters the dashed ring, so the loop reads as cause-and-effect instead of a memorized combo.
- First-play coaching now stays on-screen until the player lands one real scrap-pull vent and one real breach crack, so the vent loop teaches itself through action instead of depending on the full HUD card.
- Optional black-box recoveries now steal the main goal line while live and the HUD carries distance plus payout text, so the run stops hiding the highest-value side objective once a cache appears.
- The haul now carries a low-volume synth dispatch bed that thickens during breach pressure, so the field stops feeling sonically empty even when local asset music is absent.
- The play HUD now carries an up-next contract preview card, so the longer campaign and its next field modifier, breach, and black-box beat stay readable before the next quota hits.
- Patrol note: no new blocker found in this cohort pass; the salvage loop still balances pressure and recovery.
