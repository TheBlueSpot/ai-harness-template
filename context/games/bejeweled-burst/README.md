# Bejeweled Burst Cascade

Standalone browser-playable match-3 blitz.

Open [index.html](./index.html) in a browser to play.

## Loop

Swap adjacent gems to make lines of 3 or more. Bigger clears feed more time back into the blitz clock, and 4-gem matches forge burst gems that clear a cross the next time they pop.

## Controls

- Click one gem, then click an adjacent gem to swap.
- `Enter`: start again from overlay.
- `R`: restart instantly.

## Goal

Hit the score target before the timer expires. The board reshuffles if it runs out of legal swaps.
