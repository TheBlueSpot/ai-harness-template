# Bloons Pop-Physics

Bloons Pop-Physics is browser-playable tower defense entry focused on readable lane control, manual wave timing, chain pops, split pressure, and now short campaign progression instead of single route only.

Open [index.html](./index.html) in browser to play.

## Concept

- Three compact tower roles: dart intercepts, bomb splash, glue slow-control
- Three-operation campaign with route selection between runs, unlock progression, and per-route wave pacing
- Orchard, spillway, and night-market routes each shift pathing, threat order, and run length for more replayable variety
- Command tiers still widen range, unlock mid-run tower growth, and finish with elite late upgrades
- Gold, lead, ember, marble, and splitter waves now land in distinct campaign arcs instead of one fixed ladder

## Controls

- Mouse move previews placement and range
- Mouse click places selected tower or inspects placed tower
- `1` `2` `3` select dart, bomb, or glue towers
- `U` upgrades selected placed tower
- `N` launches next wave
- `F` cycles sim speed
- `Enter` starts or restarts run

## Campaign Notes

- Operation Orchard Bend is baseline full-length route for first clear and unlocks Spillway Switch
- Operation Spillway Switch compresses intermissions and brings shell plus volatile pressure earlier
- Operation Night Market is short finale gauntlet with dense mixed-role waves and faster decision windows
- Operation unlocks persist in browser local storage so campaign progress survives refresh
