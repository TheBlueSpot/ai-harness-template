# BurgerTime Stack

Standalone browser ladder-chase about routing falling burger layers instead of only outrunning cooks.

Open [index.html](./index.html) in a browser to play.

## Loop

Walk across every ingredient layer to stamp it loose, use pepper to buy escape space, and crush pursuers under falling food before they trap ladder routes. Stage clears when all burger pieces reach their plates.

## Controls

- `Arrow keys`: move and climb
- `Space`: pepper stun
- `Enter`: start
- `R`: restart

## Notes

- Pepper is an escape tool, but the sticky loop comes from choosing when a dropped ingredient should solve pursuit for you.
- Instant restart keeps failed ladder reads inside the learning loop instead of sending the player through long downtime.
