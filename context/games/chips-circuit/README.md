# Chip's Challenge Circuit

Browser-playable tile puzzler about route discipline. Each sector mixes chip collection with one new movement constraint, then asks you to combine keys, boots, and force floors without wasting time on slow reset loops.

## Play

Open `./chips-circuit/index.html` in a browser.

## Loop

Collect every chip in the room, unlock any required doors, and reach the exit.

The three sectors escalate in this order:
- key and door routing
- water hazard routing with flippers
- fire hazard routing with force-floor timing

## Controls

- `Arrow keys` or `WASD`: move
- `Enter`: start or continue
- `R`: restart the current sector
