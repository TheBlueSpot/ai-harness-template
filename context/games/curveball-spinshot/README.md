# Curveball Spinshot

First-person spin-pong duel about bending returns, holding the rally alive, and winning points inside a collapsing neon tunnel.

## Loop

Keep the rally alive inside a collapsing neon tunnel, then win points by bending returns past the opposing paddle. Later stages tighten the arena and add crosswind drift, so clean paddle motion matters more than brute speed.

## Controls

- Mouse or arrow keys: move paddle
- Left click, `Space`, or `Enter`: serve / continue after a point

## Play

Open `./index.html` in a browser to play locally.
