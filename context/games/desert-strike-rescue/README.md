# Desert Strike Rescue

Arcade helicopter rescue run about sweeping for survivors, landing to pick them up, and escaping before fuel or armor runs out.

## Loop

Sweep the desert for stranded survivors, land to pick them up, then return to the evac pad before fuel, armor, or ammo pressure collapses the run. Enemy armor and SAM sites force route choices instead of letting the mission turn into free hover fire.

## Controls

- `WASD` or arrow keys: thrust
- Mouse: aim nose and weapons
- Hold left mouse: cannon
- Right mouse or `Q`: rocket
- `Space`: land / pick up / unload when nearly stopped
- `R`: restart after mission end

## Play

Open `./index.html` in a browser to play locally.
