# Dig Dug: Hydro-Pressure

Browser tunnel-action remix about carving safe routes, popping pressurized water pockets, and using the flood without trapping yourself.

## Loop

- Dig a route first, then trigger nearby water pockets once enemies commit.
- Keep the main play space readable with a minimal edge HUD.
- Use instant retry so failure stays inside the learning loop.

## Controls

- Move: `WASD` or arrow keys
- Rupture nearby water pocket: `Space`
- Start or restart: `Enter` or `Space`

## Play

Open `./index.html` in a browser to play locally.
