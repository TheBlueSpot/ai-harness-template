# Fancy Pants Momentum Flow

Standalone browser sprint built around slope momentum, player alignment to the ground plane, and a nine-page sketchbook route with page-specific launch, glide, and trick-gate beats.

## Loop

- Push speed through rolling hills, launch ramps, draft lanes, and floating trick gates spread across nine notebook pages.
- Jump off the terrain normal to keep momentum through valleys and crests.
- Scoop up squiggles and thread trick gates for extra flow score while racing toward the finish gate and the final ink chase.

## Controls

- `A/D` or arrow keys: run
- `Space`, `W`, or `ArrowUp`: jump
- `Enter`: start
- `R`: restart
