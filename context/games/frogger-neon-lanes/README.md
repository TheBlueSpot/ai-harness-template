# Frogger: Neon Lanes

Browser-playable catalog entry for the `context` game collection.

- Core hook: classic lane-crossing structure remixed as a neon city sprint with moving traffic and drifting river barges.
- Session flow: title screen, active run with score, lives, and timer pressure, then win or loss restart.
- Local improvement pass: one open dock now rotates as a highlighted hot dock for a short bonus window, adding a clearer short-term route decision to the otherwise even goal row.
- Input: keyboard and touch controls both work without any external runtime.
- Re-review target: confirm the hot-dock pulse adds enough variety without making players ignore the rest of the goal row or miss the cue under late-run pressure.

Open [index.html](./index.html) in a browser to play.
