# Hardest Game

Browser-playable reflex maze built as an isolated top-level catalog entry.

Open [index.html](./index.html) in a browser to play.

## What it is

Direct-launch remake of a World's Hardest Game style dodge campaign.

## Play

Controls:

- `WASD` or arrow keys to move
- `R` to reset the current attempt
- `G` to toggle grid snap
