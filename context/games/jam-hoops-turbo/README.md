# Jam Hoops Turbo

Arcade 2v2 basketball with fast possession swaps, shove-steal pressure, and a hot-hand streak that turns clean scoring runs into blowouts.

## Play

Open `./jam-hoops-turbo/index.html` in a browser.

## Controls

- `WASD` or arrow keys move the controlled player
- `Space` shoots on offense and steals on defense
- `X` passes on offense and switches defenders on defense
- `Shift` spends turbo for burst speed
- `Enter` starts or rematches
- `R` restarts the current run

## Game Loop

Score before the defense recovers, keep the shot clock from burning out, and deny the AI easy rebounds. Two straight scores light up the heat meter and sharpen the active team's finishing.
