# Marble Madness Gyro

Standalone browser marble run built as one isolated catalog entry.

Open [index.html](./index.html) in a browser to play.

## Concept

Guide a momentum-heavy marble across six authored stages by tilting the board, locking checkpoint rings, collecting enough gems to open each finish ring, and surviving rotating gyro hazards.

## Play Loop

- Tilt with arrow keys or `WASD`.
- Use the between-stage briefings to read each board's new threat pattern before dropping in.
- Hit the glowing next checkpoint ring to secure progress.
- Collect the required gems for the current stage before entering its exit ring.
- Avoid pits, use bumpers to recover speed, and restart with `R` when needed.

## Notes

- The extension pass adds `Crosswind Causeway`, `Orbital Crown`, and `Zenith Relay` so the run now builds from onboarding into a true six-board endurance push.
- Each stage asks for controlled tilt, checkpoint timing, and enough gems to unlock the exit ring.
- The loop stays centered on momentum control and quick retries.

## Sweep learnings

- The easiest high-value answer to `wish it was longer` here is another authored board, not more menu scaffolding or systemic unlocks.
- Between-stage briefings and the progress strip help a longer run read as a deliberate course instead of one oversized board.
- The new `Zenith Relay` encore works best when it remixes earlier lane-reading demands rather than introducing a brand-new rule late.
