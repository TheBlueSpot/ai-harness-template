# Assets

This game expects optional local Kenney CC0 art in `assets/images/` and audio in `assets/audio/`.

Suggested packs:
- Space Shooter Redux: `backgroundStars.png`, `laserRed08.png`, `laserBlue08.png`
- UI Audio: `tick_002.ogg`, `powerUp8.ogg`, `jingle_win_00.ogg`
- Digital Audio: `impactMetal_002.ogg`, `lowThreeTone.ogg`
- A Kenney city or tower sprite pack can supply `building_A.png` and `towerDefense_tile249.png`, but the game falls back to vector cities/turret if those files are absent

Kenney asset pages are public domain CC0:
- https://kenney.nl/assets/space-shooter-redux
- https://kenney.nl/assets/ui-audio
- https://kenney.nl/assets/digital-audio

If any files are missing, `index.html` still runs with procedural graphics and synthesized sound.
