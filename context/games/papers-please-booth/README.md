# Papers Please Booth

Papers Please Booth is a compact inspection game about reading a queue, checking rule cards, and making fast document calls.

Open [index.html](./index.html) in a browser to play.

## Core Loop

- Read the current rule card.
- Inspect each entrant's papers for matching name, permit, and expiry details.
- Approve clean document stacks and reject bad ones before strikes pile up.

## Play Path

- Survive each shift by keeping your calls accurate while the queue speeds up.
- Learn the rule changes quickly enough that the booth stays readable under pressure.
