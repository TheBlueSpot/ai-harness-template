# Peggle Ricochet

`./peggle-ricochet/` is a browser-playable peg-bounce score attack about reading bank shots instead of brute-forcing straight lines.

## Play

Open [index.html](./index.html) in a browser to play.

## Loop

- Clear every orange peg before the shot supply runs out.
- Recover spent shots by catching the ball in the moving bucket.
- Restart instantly with `Enter` or `R` so angle experiments stay inside the learning loop.

## Controls

- Aim with the mouse.
- Fire with mouse click or `Space`.
- Start or retry with `Enter`.
- Full reset with `R`.
