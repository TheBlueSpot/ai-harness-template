# QWOP Inverse

Browser-playable hurdle runner built around unstable limb-by-limb control. The loop is about pacing the runner, managing lean before it cascades into a fall, and clearing spaced hurdles without overcorrecting.

## Play

Open `./qwop-inverse/index.html` in a browser.

Controls stay visible in the start overlay:

- `Q/A` left thigh
- `W/S` right thigh
- `O/K` left calf
- `P/L` right calf
- `Z/,` left sole
- `X/.` right sole
- `Enter` start

## Notes

This entry is isolated to its own folder and boots directly from local files with ES module imports under `./src/`.
