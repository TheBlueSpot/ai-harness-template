# SkiFree Avalanche

Arcade downhill run about clean gate lines and panic management. The run stays readable: one next gate, one rising threat, and instant restart when the avalanche finally closes.

## Play

Open [index.html](./index.html) in a browser.

## Loop

- Thread slalom gates to build score and buy breathing room from the avalanche.
- Hit ramps and hold pace so the pressure wall does not collapse the run.
- Avoid trees, rocks, and fallen logs on the finish push to the lodge.

## Controls

- `Arrow keys`: steer and pace
- `Space`: jump ramps and logs
- `Enter`: start or restart
