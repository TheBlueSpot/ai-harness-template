# Asset Notes

`skylord-defender` uses permissive OpenGameArt assets for the ship, backdrop, and audio layer.

Visual sources:

- [CC0 Backgrounds](https://opengameart.org/content/cc0-backgrounds) for the grid backdrop
- [Ship Sprites](https://opengameart.org/content/ship-sprites-0) by `Prime_8`

Audio sources:

- [Space Echo](https://opengameart.org/content/space-echo) by `Centurion_of_war`
- [Laser](https://opengameart.org/content/laser) by `frosty ham`
- [Explosions](https://opengameart.org/content/explosions-4) by `EZduzziteh`

Local files live under `images/` and `audio/`. The game still falls back to procedural canvas art if any asset is missing.
