# Sokoban Vault Shift

Standalone browser-playable crate-routing puzzle built as one isolated catalog entry.

## Play

Open [index.html](./index.html) in a browser to play.

## Concept

Guide a vault runner through ten security floors by pushing amber power cells onto glowing sockets, then layer relay shutters and runner-only warp pads into the late-campaign routes.

## Play Loop

- Move with the arrow keys or `WASD`.
- Push power cells one tile at a time onto every glowing socket.
- Use `Z` to undo a bad shove and `R` to reset the current room.
- Walk through the unlocked vault door to reach the next floor.
- Hold blue relay switches with a body or spare power cell whenever a shutter gate needs to stay open.
- Use magenta warp pads to reposition the runner across split routes without moving any power cells.

## Notes

- Ten authored floors now ramp from clean crate-routing basics into relay-switch shutter puzzles and warp-pad repositioning, so the run lasts longer and adds a readable late-campaign mechanic instead of repeating the same room shape.
