# Assets

The Last Stand: Barricade Breach is intended to run without external asset dependencies.

- Use original, public-domain, or CC0-style media only.
- Keep sourced material documented at the point of use.
- Favor procedural canvas rendering for the battlefield, characters, and effects.
- If you add audio or art later, note the creator, license, and source link here or in a nearby high-level note.
