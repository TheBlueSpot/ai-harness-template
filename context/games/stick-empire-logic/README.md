# Stick War: Empire RTS

Browser RTS skirmish built around gold income, unit production, selection, and direct possession.

## Play

Open [index.html](./index.html) in a browser.

Core controls stay visible in the HUD:

- Left drag selects friendly units.
- Left click possesses a friendly unit.
- Right click issues the active command.
- `M`, `F`, and `H` swap move, attack-move, and harvest orders.
- `P` toggles possession.
- `Space` fires the possessed unit's attack.
