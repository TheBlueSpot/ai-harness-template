# Storm the House: Ballistic Siege

Browser siege defense about holding a house line against escalating stickman waves.

Open [index.html](./index.html) in a browser to play.

## What It Is

You aim and fire from the house while enemies rush the barricade. Short intermissions let you spend gold on stronger firepower, better support units, and sturdier defenses before the next surge lands.

## Core Loop

- Stop attackers before they break the house.
- Earn gold from kills and wave clears.
- Buy upgrades between waves.
- Push deeper until the line collapses or the run is won.
- The live HUD stays small and edge-anchored so health, ammo, gold, and wave state remain readable during the fight.

## Controls

- Mouse: aim
- Hold click: fire
- Start Run: begin the siege
- Launch Next Wave: leave intermission and resume combat

## Notes

- Open [index.html](./index.html) in a browser to play.
- The fight clears held fire on pointer release or focus loss so the line does not keep shooting after a stray click exit.
- Keep the folder isolated so direct browser boot still works from `index.html`.
- Patrol note: keep the line readable and the intermission loop fast.
