# Toss the Turtle: Atomic Blast

Browser canvas launcher game with a main menu, active midair control, an upgrade shop, hazard and bomb rebounds, stylized impact particles, and a results screen.

## Play

Open [index.html](./index.html) in a browser to play.

## Presentation

- Visuals are procedural or generated at runtime.
- Asset policy stays public-domain or generated only.
- The gore particle system is stylized arcade debris, sparks, and dust.

## Notes

- Upgrade pacing, rebound hazards, and particle-heavy impacts are the main texture; the run should stay readable even when the screen gets loud.
- See [assets/README.md](./assets/README.md) for asset policy.
- Launch stays direct from `index.html`, so the catalog entry remains browser-native with no extra setup.
