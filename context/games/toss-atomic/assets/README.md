# Asset Notes

All `toss-atomic` visuals are generated in code. No third-party art, sprites, or audio are required for the current shell.

## Asset Policy

- Use procedural canvas drawing for backgrounds, objects, and effects.
- If future hand-authored art is added, keep it public-domain, CC0, or otherwise safe for reuse.
- Keep impact effects stylized and non-realistic.
