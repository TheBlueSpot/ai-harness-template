# Velocity Grind Assets

Local assets are vendored under `velocity-grind/assets/` so the game runs offline without extra tooling.

## Sources

- `images/` and `audio/` use Kenney CC0 packs.
- Sprite sources: Kenney Space Shooter Redux. https://kenney.nl/assets/space-shooter-redux
- SFX sources: Kenney Sci-Fi Sounds. https://kenney.nl/assets/sci-fi-sounds

## Local Paths

- Rider sprites: `images/playerShip1_*.png`, `images/playerShip2_*.png`, `images/playerShip3_*.png`
- Menu emblem: `images/ufoBlue.png`
- SFX: `audio/laserSmall_000.ogg`, `audio/impactMetal_001.ogg`, `audio/spaceEngineSmall_002.ogg`, `audio/lowFrequency_explosion_001.ogg`, `audio/explosionCrunch_002.ogg`
