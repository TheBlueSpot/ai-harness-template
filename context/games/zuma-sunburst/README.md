# Zuma Sunburst

`./zuma-sunburst/` is a standalone browser-playable marble-chain shooter. The pressure comes from one readable curved lane, fast color swaps, and low-friction retry when the chain reaches the sun gate.

## Play

Open `./zuma-sunburst/index.html` in a browser.

## Loop

Hold the gate by inserting shots into the moving chain and clearing groups of three or more matching colors. Large clears drag the head back, so the run rewards aiming into future pressure instead of reacting late at the gate.

## Controls

- `Mouse`: aim
- `Click` or `Space`: fire
- `Shift`, `X`, or right click: swap current and next color
- `Enter`: start
- `R`: instant retry after win or loss

## Notes

- Open [index.html](./index.html) in a browser to play.
- Keep retry immediate so the learning loop stays tight.
