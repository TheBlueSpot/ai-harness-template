# Hexcells Logic Grid

Browser-playable hex deduction puzzle with three authored boards, flag-and-chord play, and fast restart flow.

## Play

Open `./hexcells-logic/index.html` in a browser.

## Loop

Reveal every safe hex on each board. Right click to flag suspected mines, click revealed clues to chord nearby cells once your flags match the number, and survive the full run before your shields run out.

## Controls

- `Left Click`: reveal a hex
- `Right Click`: flag or unflag a hex
- `F`: toggle flag mode for left-click-only play
- `R`: restart the full run

## Distinct Note

This entry stays in puzzle territory instead of action pressure: the challenge is spatial deduction on a hex lattice, with authored board progression rather than procedural survival.
