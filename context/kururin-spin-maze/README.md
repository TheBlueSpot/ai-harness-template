# Kuru Kuru Spin Maze

Precision maze game built for direct browser play from `./index.html`.

## Loop

Pilot the center of a constantly spinning rod through tight corridors, scoop up every battery cell in the sector, then guide the full frame into the exit gate. Every wall scrape or spark-rail hit burns shield, so the run is about calm line choice more than speed alone.

## Controls

- `WASD` or arrow keys: move
- Hold `Shift`: precision drift
- `Enter`, `Space`, or click the overlay button: start / continue
- `R`: restart after a crash or full clear

## Win / Lose

Clear all three sectors to win. Lose if shield drains to zero.
