# Liquid Velocity Assets

Environment art in this folder comes from public-domain sources and stays local to this game folder.

## Sources

- `terrain-cavern.png`: Openclipart public-domain catalog, image id `305810`, downloaded from `https://openclipart.org/image/800px/305810`
- `spikes-strip.png`: Openclipart public-domain catalog, image id `188235`, downloaded from `https://openclipart.org/image/800px/188235`
- `goal-gate.png`: Openclipart public-domain catalog, image id `301927`, downloaded from `https://openclipart.org/image/800px/301927`
- `background-mist.png`: Openclipart public-domain catalog, image id `330513`, downloaded from `https://openclipart.org/image/800px/330513`

## Usage

- Terrain art is used as the solid-tile texture.
- Spikes and gate art mark hazards and the goal.
- Mist art sits in the far background to keep the cave readable without flattening the playfield.
