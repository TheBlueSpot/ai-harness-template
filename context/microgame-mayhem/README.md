# Microgame Mayhem

Arcade microgame gauntlet built as an isolated browser-playable catalog entry.

## Loop

Short one-screen challenges rotate back-to-back. Clear the objective before the timer expires, keep your three lives, and survive long enough for the prompt speed ramp to matter.

## Controls

- Move with `Arrow Keys` or `WASD`
- Use `Space` or `Enter` for action / confirm
- Press `R` to restart after a run ends

## Notes

- Open `./index.html` directly in a browser to play
- HUD stays compact so the active prompt remains readable during each switch
