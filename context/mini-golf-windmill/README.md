# Mini Golf Windmill

Browser-playable mini golf run built as one isolated catalog entry.

## Play

Open [index.html](./index.html) in a browser to play.

## Loop

Drag from the ball to line up a shot, release to hit, and clear six authored holes while windmills and sand punish weak angles.

## Notes

Keep the scorecard clean by using bank shots around wooden blockers instead of forcing straight lines through the rotating hazards.

## Recent Learning

The review note about the aim readback being `a arrow not a circle` was real. The drag preview needed to show direction first, not just a landing dot, and close putts felt harsher than the cup art implied.

## Next Todo

If another pass is needed, the next leverage is bank-shot teaching on later holes so first-run players can read the intended ricochet lane before they discover it by waste strokes.
