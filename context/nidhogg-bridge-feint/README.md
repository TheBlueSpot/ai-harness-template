# Nidhogg Bridge Feint

Browser-playable bridge duel built as a local catalog entry.

- Core hook: a hanging-bridge fight where lane swaps, spear throws, and parries decide who pushes the line first.
- Session flow: start from the title card, race to five points, and rematch immediately after each banner drop.
- Gameplay texture: each lane changes throw angles, clean parries punish reckless thrusts, and dropped spears create short shove scrambles before weapons return.
- Launch path: open `index.html` directly in a browser.
