# Pants Vector

Browser momentum platformer built around a flowing spline track, fast downhill carry, and hazard gaps that punish sloppy line choice.

## Play

Open [index.html](./index.html) in a browser to play.

Controls:
- `Left` / `A`: lean left
- `Right` / `D`: lean right
- `Space`: jump and start
- `Shift`: dash for extra drive
- `R`: restart after a wipe

## Goal

Keep speed through the carved track, clear the hazard pits, and reach the finish marker without getting dumped off the line.
