# Paperboy Route

Browser-playable delivery arcade about holding a neighborhood route together under timing pressure.

## Why It Exists

This catalog entry covers lane-based delivery timing instead of combat or pure racing. The run is about reading curb hazards, lining up quick throws, and preserving control clarity while the street keeps pushing forward.

## Core Loop

- Ride across three street lanes while the route auto-scrolls toward the next block.
- Throw papers into open mailboxes for score and route progress.
- Dodge cars, dogs, cones, and drains that punish missed positioning or late lane swaps.

## Play Pattern

The first block teaches in motion. A nearby prompt marks the first mailbox throw, then the route adds dogs and parked traffic so each new risk appears right before it matters.
