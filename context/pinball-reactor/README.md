# Pinball Reactor

Pinball Reactor is a browser-playable arcade table inspired by fast combo-heavy digital pinball. The run stays focused on a single table: light reactor targets, send clean ramp shots, lock balls for multiball, and keep drains from ending the score chase too early.

## Play

Open [index.html](./index.html) in a browser to play.

## Loop

- Build score with bumpers, target banks, and sling rebounds.
- Charge the reactor through completed target banks and ramp shots.
- Lock two balls to trigger multiball and create a safer scoring window.
- Clear the table by reaching the score goal before all balls drain.

## Controls

- `Left Arrow` or `A`: left flipper
- `Right Arrow` or `D`: right flipper
- `Space` or `Enter`: launch ball, start, or restart
- `Shift`: nudge the lower table
