# Skylord Defender

Browser-playable Defender-style rescue game kept isolated in its own catalog folder.

## Play

Open [index.html](./index.html) in a browser.

## Concept

- Sweep the skyline to intercept raiders before they carry civilians off-screen.
- Drop temporary turrets to stabilize dangerous lanes while you manage rescues and wave pressure.
- Terrain damage and salvage pickups turn each pass into a risk-reward route choice instead of a pure survival loop.

## Notes

- The folder is self-contained for direct browser play.
- Opening waves were retuned to be less punishing: the first passes now field fewer bombers, slower reinforcements, extra turret charges, and a larger between-wave shield refill.
- Asset credits and source notes live in [assets/README.md](./assets/README.md).
