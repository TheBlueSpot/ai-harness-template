# Spelunky Pocket Ruins

Browser-playable catalog entry for the `context` game collection.

- Core hook: a compact cave run focused on rope placement, bomb-made shortcuts, and trap lines you can read before they fire.
- Session flow: descend through one fixed ruin, collect three idols, wake the moon gate, and escape without burning through all your supplies.
- Gameplay texture: soft-stone chokepoints make bombs part of the route, tall shafts reward proactive rope drops, and arrow traps telegraph their shot path so failure stays inside the learning loop.
- Latest pass: player and bomb collision now resolve in short stepped slices instead of one big destination jump, so fast drops stop skipping through floor tiles and wall contact stays more trustworthy during rough falls.

Open [index.html](./index.html) in a browser to play.
