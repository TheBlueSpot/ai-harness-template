# Spy Hunter Intercept

`spy-hunter-intercept` is a browser-playable highway combat chase about breaking escort waves before a command truck escapes up the road.

## Play

Open `./spy-hunter-intercept/index.html` in a browser.

## Controls

- `WASD` or `Arrow Keys`: steer through lanes and shoulders
- `Space`: fire
- `Shift`: dock with a nearby support van for repairs and a missile burst
- `Enter`: start or restart

## Loop

Clear two convoy sectors by surviving traffic pressure and destroying enemy vehicles. Support vans create short missile windows that help crack denser waves. The final sector sends in a command truck boss, and the run ends in either a highway clear or a wrecked interceptor.
