# SSX Trickstorm

`SSX Trickstorm` is a browser-playable downhill snowboard run focused on speed lines, ramp timing, and clean trick landings. The run is built as one isolated catalog entry with direct local boot from its own folder.

## Play

Open [index.html](./index.html) in a browser to play.

## Controls

- `A` / `D`: shift lanes
- `W`: tuck for speed
- `S`: scrub speed
- `Space`: jump
- `J` / `L`: spin in the air
- `K`: hold grab
- `Shift`: spend boost
- `Enter`: start
- `R`: restart after the run

## Goal

Bank points by landing spins and grabs cleanly, thread the central gates, avoid rocks and trees, and clear the course before the finish.
