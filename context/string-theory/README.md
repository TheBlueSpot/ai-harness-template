# Space Invaders: String Theory

Single-file browser game experiment for `context`.

- Core hook: invaders form a live elastic lattice, so every hit kicks momentum through the remaining swarm.
- Session flow: menu, active run, win screen, and lose screen with fast restart.
- Presentation: particle bursts, layered space backdrop, HUD, and optional Kenney public-domain art/audio if matching asset files are dropped into `assets/kenney/`.
- Fallback behavior: if external assets are absent, the game still runs with built-in vector visuals and synth audio.

Open [index.html](./index.html) in a browser to play.
