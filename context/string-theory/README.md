# Space Invaders: String Theory

Browser-playable catalog entry for the `context` game collection.

- Core hook: a Space Invaders remix where the formation behaves like a live elastic lattice, so every hit whips momentum through the swarm.
- Session flow: launch from the title card, break four escalating formations, and restart instantly on win or loss.
- Gameplay texture: the HUD stays edge-anchored, the start/fire prompt remains visible near the action, and optional asset drops fall back to built-in vector visuals plus synth audio.

Open [index.html](./index.html) in a browser to play.
