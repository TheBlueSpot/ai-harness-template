# Tapper Last Call

Browser-playable catalog entry for the `context` game collection.

- Core hook: a lane-service arcade shift where the bartender serves fast-moving patrons and catches the empty mugs before they shatter on the bar.
- Session flow: open the bar from the title card, survive three increasingly fast shifts, and keep the lane rhythm intact through serves and return catches.
- Gameplay texture: the active bar stays highlighted, first-use prompts sit on the exact lane that matters, and the HUD stays edge-anchored so the rush remains readable.

Open [index.html](./index.html) in a browser to play.
