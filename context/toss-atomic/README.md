# Toss the Turtle: Atomic Blast

Browser canvas launcher game with a main menu, active midair control, an upgrade shop, hazard and bomb rebounds, stylized impact particles, and a results screen.

## Presentation

- Visuals are procedural or generated at runtime.
- Asset policy stays public-domain or generated only.
- The "Gore Particle System" is implemented as arcade-style non-realistic burst shards, sparks, and dust.

## Run

Open in a browser or serve the folder locally.

## Notes

- Architecture is split across launch dynamics, collisions, UI/shop state, rendering, and particles.
- See [assets/README.md](assets/README.md) for asset policy.
