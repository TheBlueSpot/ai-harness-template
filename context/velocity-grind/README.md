# Velocity Grind

Velocity Grind is a browser-playable hover-course runner about threading gates at speed without letting the line break. Each rider changes the feel of the same route, so the run is about picking a handling profile, holding stability through corners, and cashing clean gate passes into score.

## Controls

- `Left` / `Right` or `A` / `D` to steer
- `Up`, `W`, or `Space` to throttle
- `Down` or `S` to brake
- `Enter` or `Space` to advance menu prompts
- `Esc` to return to menu

## Play Loop

- Pick one rider with a distinct speed, grip, and flow profile
- Stay near the route center to score clean gate passes and build combo
- Protect stability through turns and landings so the run does not collapse before the finish
- Clear the full course for a win, or recover quickly after a failed line and retry
