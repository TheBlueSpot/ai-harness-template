# Xevious Sky Assault

Direct-boot vertical shooter with split air and ground targeting, trench radar pressure, and fast retry flow.

## Play

- Move with arrow keys or `WASD`.
- Fire air targets with `Space` or `Z`.
- Fire ground targets with `X` or `Ctrl`.
- Start or restart with `Enter` or `Space` from the menu and result screens.

## What To Expect

- Air threats and trench targets need different shots, so route each pass with intent.
- The radar climbs as the run advances, which keeps pressure readable without adding clutter.
- Losses restart quickly so the loop stays inside the learning rhythm.

## Direct Play

- Open `./index.html` in a browser.
- No install step or launcher is required.
