# Typing Zombie Siege

`Typing Zombie Siege` is a small browser game with a direct `index.html` launch path.

## Launch

Open `typing-zombie-siege/index.html` in a browser.

## Controls

- Type letters to build the current word.
- `Backspace` removes the last letter.
- `Enter` submits the word.
- `Escape` resets the run.

Focus is set on the game canvas at start, so typing works without extra clicks after launch.
